1.9

Version 1.9 has been split in many community versions due to controversial features, the following terminology will be used for the remainder of this section:

Unsafe releases contain code that is able to shut down the player's computer. The command ran is shutdown -s -t 0 on Windows and shutdown -h now in Unix-based systems, including Linux and MacOS. This is the original version of the mod.

Safe releases remove the code above, rendering the game unable to shut the player's computer down.

Moonfix releaes remove a line of code that sets the player's render distance to 2 via settings.
