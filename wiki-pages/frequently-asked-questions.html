Frequently Asked Questions

SOURCE MIRROR // official wiki ->

Welcome to The Broken Script's Frequently Asked Questions page. Here, you'll find everything you need to know to get the mod working, what to do if it breaks, and find general information about what's inside the mod itself. = The Broken Script FAQ =

📥 Installation & Setup

How to install The Broken Script?

Use Modrinth.

What is the best version of Broken Script to play?

The answer will be up to you. You must download the community patch if you are determined to play on version 1.20.1 even though mod development has ceased for this version. If you do want to play the newest version, use the official sources.

Why is TBS not loading?

TBS requires several dependencies, which include Kotlin for Forge, Fzzy Config, and Geckolib. Make sure you have all three mods installed.

I still get errors when launching the game.

Read the text of the error carefully. If you see the word Geckolib — most likely, you have not installed it. Or maybe you're trying to run the 1.20.1 mod on 1.21.1 NeoForge.

Why is the mod now being developed with Neoforge?

According to the developers, Neoforge makes it easier to develop the mod. Since Neoforge is available starting with the 1.21.1 version of Minecraft, current mod builds are accordingly only available on this version. No, the latest builds will not run on Forge.

⚙️ Configuration & Commands

How do I customise the mod for myself?

Customisation of the mod is available via config (while in game, pause the game, click on the mods' menu, locate The Broken Script).

Why can't I use commands in my world?

Commands are disabled by default due to the influence of Integrity on the world. They can be re-enabled in the 1.21.1 version of The Broken Script using in-game config settings (enable cheats).

How to turn off the VHS filter? The black bars on the screen? '/removevhs' no longer works.

It can be disabled using config settings.

How do I remove the old cave generation?

The data pack “Nostalgia Helper Worldgen” returns the old cave generation system. Switch it off before creating the world.

What shaders can I use?

Recko's shaders are approved by the mod developers. This doesn't mean that other shaders are incompatible with the mod, but those that modify the moon are definitely not recommended for use.

🧩 Gameplay Mechanics & Features

Will The Broken Script crash my game?

Yes. Game crashes are a core gameplay mechanic of The Broken Script and are caused by the Entities. In the 1.20.1 version of The Broken Script, the command /TBS_config can be used to control certain events like game crashes. The 1.21.1 version, however, includes 'Fzzy Config' as a dependency, which allows for much finer control of the mod. You can access this by clicking on the 'Mods' button in the pause or main menu, selecting 'The Broken Script' and clicking 'Config' in the bottom-left of the menu.

Can I lose my world?

Yes. The Entities are capable of banning you from your world. It is however toggleable with an option. To reverse a ban (eg in older versions), delete the 'entities' folder in your Minecraft profile directory. Please note this will delete all entities in the world, including pets, villagers, and mobs. Villagers will not respawn.

Why is the moon purple? / Why is there no moon in the sky? Is it broken?

The moon was broken in the old builds. It is fixed in the latest version of The Broken Script. We strongly advise you to update the mod to the latest version.

The sun/moon don't move, day/night don't end, what do I do?

Stopped time is an intended feature caused by a certain random event. It is not permanent and can be reversed by either that event happening again or using /gamerule doDaylightCycle true.

Why can't I use /TBS_Config?

The reason you can't use /TBS_Config is because you don't have cheats enabled. See the devmode section above.

Are there any faces inside the mod?

That would be a custom edit of the mod made by Swayle (or other YouTubers). No, these black figures with faces are not separate secret entities, but edited r2, and no, the original mod does not feature any ‘scary’ PNG faces. No, the official Discord server does not offer a custom texture pack that includes those faces.

Is The Broken Script safe for my PC?

All versions of The Broken Script published on Modrinth are safe for your computer and will not harm it in any way.

Is TBS compatible with multiplayer?

Yes, starting from the version 1.10.0 it is officially compatible.

🔨 Troubleshooting

I am having TPS issues / My game is lagging as if I am playing on the actual server

Verify whether you are using the 1.9.4 version of the mod or not. This build is notorious for its severe bug, which results in uncontrollable Circuit spawnings, which in turn cause significant TPS issues.

Why does my UI look weird?

Either you need to switch from English (US) to English (UK) or open Resource Packs and put mod resources over the default package. Follow the convention of 'colour, favourite, behaviour'.

Why do I see a notification when I launch the game that Sodium and The Broken Script are incompatible?

Sodium can indeed cause texture problems, but this happens to a minority of people. We suggest ignoring this warning and continue playing the game. But in case you notice broken textures, Sodium will have to be uninstalled.

Blocks are not rendering / I'm having issues with textures, what should I do?

Try removing Sodium from your modpack. Note: this kind of problem seems to happen in newer GPUs that have explicit support for Vulkan, and not OpenGL, which Minecraft uses. Try looking for a driver update that adds support to OpenGL for your card. If you don't have one, remove sodium.

I'm using CurseForge to play the game and when I add The Broken Script to my mods' folder, it shows up in the launcher in some cryptic way.

Ignore it.

🌒 Entities & Lore Interactions

When will things begin?

Null should join within the first night, but it might take you a few nights in your world before you start seeing more entities and for the game to ramp up. If you want to interact with Null, visit his page to know more about his interactions.

What's the reputation system? How do you increase/decrease it?

Main article: Reputation The reputation system is a hidden statistic that changes based on how you interact with entities. In general, surviving/avoiding entities can give reputation, while triggering entities can decrease it.

Where is The Broken End?

The Broken End is tied to the Moon phases.

I encountered a Chicken in the caves. Was that Circuit?

No, it was one of the entities that failed to spawn properly and ended up spawning a Chicken. It is harmless. (RedstoneWizard08 has also stated that it is a joke in which a Chicken Jockey is supposed to spawn, but only a Chicken spawns because Circuit is pausing mob spawning. It is a reference to the famous quote from A Minecraft Movie, where Steve says, “Chicken Jockey!”)

How can I encounter Integrity?

Integrity is currently optional and only in the final parts of the mod, he will not appear during normal gameplay.

Null left the game before even appearing in the world in the first place / Null left the game, what does it mean?

That is one of the random events. This event is considered to mean nothing special (at this point). Despite the notification that Null is out of the game, he is still present in the world. ---- = spectrum_11 FAQ =

📦 What is spectrum_11?

What is spectrum_11 and do I need to download it?

Spectrum_11 is a hidden mod found when opening The Broken Script's .jar file as an archive, and is located in the 'Consciousness' directory. It is technically separate from The Broken Script. In some versions it is not present due to wendigodrip forgetting to add it. You can find versions of it in the mod archive.

💻 System Impact

Why is my game/computer lagging so much?

If you are playing with spectrum_11 present, it can open multiple instances of Windows PowerShell or Linux shell, potentially interfering with system performance and crashing your machine.

Why does my text font look so messed up?

This is a feature of spectrum_11. It intentionally modifies the in-game font display.

Is spectrum_11 safe?

It is not malware and will not damage your system files, but it can execute PowerShell commands to adjust system volume, shut down your computer, and affect OS-level settings. These behaviours are not part of The Broken Script itself. Do not play with spectrum_11 unless you are prepared for the consequences. = Wiki =
