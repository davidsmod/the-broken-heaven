Commands

SOURCE MIRROR // official wiki ->

The Broken Script contains a lot of commands, almost all of them being for administrators only.

Player commands

/tbsc

The /tbsc command is seemingly for testing purposes, it is available to all players. It stands for TBS Client Commands. It previously was one of the ways to modify the configuration of the mod, but as of 2.0 it only has a minimal amount of commands, none of them related to the config. As the name indicates, these commands are not available on a dedicated server.

boss_end

{| class="wikitable" ! Name !! Values/Type !! Description |- | Section || start / end || start: plays the end cutscene of the mod, moving the camera up and showing the end credits shortly after. end: Shows the end credits directly, skipping the aforementioned cutscene. |} A test command, likely used to make sure the ending cutscene was working well before release. Source: FinalCutsceneHandler.CUTSCENE.start() / .end().

camera

{| class="wikitable" ! Name !! Values/Type !! Description |- | Axis || z || The axis, only z is available. |- | Amount || Number || The value to override the camera in the specified axis, in radians. |} This command rotates the camera in the specified axis by Amount radians. Source: CameraZAxisKt.setAngle.

figure

This command will crash the game as it tries to load a file that is not present in the release versions of TBS. If it were to work, it would open a new Java Swing panel that would animate a spritesheet located at thebrokenscript/textures/testing/infect_&lt;frame&gt;.png, where &lt;frame&gt; would be a number between 0 and 7 and updated every tick. When the animation would have finished, it would have closed itself and frozen Minecraft for 2 seconds.

moonrise

Lets you control the ambience of Fractured, even outside of the intended location.

init

Creates the internal class that handles the Moon Rise ambience (MoonRiseAmbience).

stage

{| class="wikitable" ! Name !! Values/Type !! Description |- | Stage || Integer (0-3) || What stage/level to set the ambience to. |} Source: Jimbo.MOONRISE.applyStage(stage).

test

{| class="wikitable" ! Name !! Values/Type !! Description |- | Sound || Sound asset || The sound to play. |- | Loop || Boolean || Self explanatory. |- | Volume || Number || How much to increase the base volume by, where 1 = 100%. |- | Pitch || Number || Pitch multiplier, where 1 = 100%. |- | Gain || Number || Additional volume multiplier, setting the gain from the audio engine this time. 1 = 100%. |} Although it looks like a copy of /playsound, this command uses BrokenCore's Fancy Audio API to play sounds. Source: FancyAudio.play(...).setGain(gain).

Server commands

/tbs

The /tbs command handles all commands related to the mod's state. These commands are locked behind requiring administrator permissions, whether it'd be through /op or the server console. Note: All /tbs dev subcommands require the cheats config to be enabled in BrokenCore (BCConfigs.getEnableCheats), otherwise the command will fail with "Cheats are not enabled!".

reputation

This command allows you to see your reputation. As an admin, you can get another player's reputation by using /execute as &lt;player&gt;. Mechanism (source): checks PlayerVariables.entityReputation and displays a tier:

Rep ≤ 25 → BAD (hover text: "Null is pissed and his hatred for you is at maximum. Expect hell from null. Null will now more often attack the player.")

25 75 → GOOD (hover text: "Null is cool and doesn't care about you being here. Null will rarely hurt the player.")

Note: The tier labels (BAD / NORMAL / GOOD), hover descriptions, message prefixes (Reputation value: / Reputation:), and the trailing (hover for more information) hint are all hardcoded English strings in the source code, not loaded from the lang system. Players will always see English regardless of the resource pack. This command must be executed by a player; running it from the console returns -1.

devmode

{| class="wikitable" ! Name !! Values/Type !! Description |- | Code || Integer || The special code to input. |} Allows entering special codes set by the developers. Currently available codes are:

2018: Spawns 1000 Circuits at your current location, printing Have fun! in the chat/console.

544253: Spawns 1000 The Broken Ends at your current location, printing Have fun! in the chat/console.

Other codes print "Dev mode code is invalid!".

dev

Most of the /tbs commands are located in this subcommand. Note: All commands in this category require the cheats config to be enabled in BrokenCore.

arena

Various commands to test the Integrity boss fight, this can be used to spawn Integrity in the overworld if you want that for some reason.

start

Starts the Arena at the player's current location. Success message: Have fun...

create

Creates a new Arena instance and adds the current player to the participants list. Success message: Created arena!

next

Advances the Arena to the next phase (arena.nextPhase()). Fails if no Arena is active.

kill_phase_3

Kills Integrity in Phase 3 of the active Arena (arena.getPhase3().getIntegrity().kill()). Fails if no Arena is active.

destroy

Destroys the current Arena (arena.reset(); Arena.instance = null). Fails if no Arena is active.

arms

Spawns the "wacky wavy inflatable gas station arms" in Phase 3. Success message: Spawned wacky wavy inflatable gas station arms!

Removes the entire chunk the player is standing on. Success message: Successfully cleared the chunk at (X, Z)

code

Commands related to the Corrupted Command Block.

get

Returns the current code for the Corrupted Command Block (read from MapVariables.code).

reroll

Resets the code to a fresh random string of 6-12 characters (StringExt.nextString(random, length, ...)).

status

Prints whether the code has been applied (MapVariables.codeApplied).

coord

{| class="wikitable" ! Name !! Values/Type !! Description |- | Where || clanvoid / maze / wood / stone / day_A || Which part of the void to get the polaroid coordinate from. |} Returns the X and Z coordinate of the Polaroid in the specified location of Clan Void. The returned coordinates are chunk centers, computed as floorDiv(coord, 16) * 16 + 8.

/tbs dev coord clanvoid → Wooden floor polaroid of Clan Void

/tbs dev coord maze → Maze floor

/tbs dev coord wood → Wooden floor

/tbs dev coord stone → Stone floor

/tbs dev coord day_A → Day A dimension

Circuit-related commands to inhabit and discard creatures.

{| class="wikitable" ! Name !! Values/Type !! Description |- | Who || Entity || The entity to inhabit. |} Sets the CircuitInhabited flag on the targeted entity to true, allowing Circuit to possess it. The success message uses CMD_INHABIT_SUCCESS lang key.

{| class="wikitable" ! Name !! Values/Type !! Description |- | Who || Entity || The entity to discard. |} Forcefully removes the targeted entity or entities from the world (non-player entities only). Useful for entities that are immune to the normal /kill damage type. Implemented in brokencore.

Various event-related commands (from brokencore).

{| class="wikitable" ! Name !! Values/Type !! Description |- | Who || Player(s) || Players to trigger all events on. |} Runs every single registered event on the targeted players. Good luck!

Prints all scripted events part of progression. Requires the Event Debug config in BrokenCore to be enabled. The scripted events include: MoonCorruptionStoryEvent, TXTStoryEvent, NullBookStoryEvent, CoordsStoryEvent.

force

{| class="wikitable" ! Name !! Values/Type !! Description |- | Event || Event asset || The event to execute. |} Forces the specified event to execute.

random

Triggers a random event using the same system as the event scheduler.

schedule

Prints various information regarding events, including:

How many events are registered

How many events the engine executes per in-game day

Whether events are enabled globally

Pre-scheduled upcoming events (pending slots)

reschedule

(Dev environments only) Clears all schedules and regenerates them on the next tick.

void_box — Stage 2 Arena Border (player)
