Reputation

SOURCE MIRROR // official wiki ->

The Broken Script contains a reputation system that adapts to how the player interacts with the mod. Reputation almost exclusively affects Null, but can also change what structures spawn and allows certain Random Events to happen. Reputation is split in tiers, which are BAD ( 75). Reputation cannot go below 0. The default value for reputation is 50. If cheats are enabled, or the player is an operator, they can run the command /tbs reputation to get their reputation value and tier. Users with such permissions can also modify their own reputation using /tbs dev reputation add. ]] In multiplayer servers, reputation is separate for each player, meaning a nice player can have a GOOD reputation while a bad player has a BAD reputation. = Changing Reputation = Reputation gain/loss is categorized with these names: {| class="wikitable mw-collapsible" |+Reputation values !Name !Change |- |Teeny Tiny |1 |- |Baby |5 |- |Minor |10 |- |Small |15 |- |Rare |20 |- |Medium |25 |- |Well Done |30 |- |Huge |35 |- |Congratulations |50 |- |Regain Half |special; lets you regain halfof your most recent loss |}

Good

Disabled Events

GOOD reputation disables the following events:

Madness 1

Disabled Entities

GOOD reputation disables the following entities:

Null (Mining)

One of the triggers for Null (Chase) from Null (Watching)

Enabled Structures

GOOD reputation enables certain structures that are not otherwise spawnable:

Giift

Bad

Chat Responses

BAD reputation allows positive chat responses to give reputation.

Enabled Events

Having BAD reputation enables the following events to occur:

Place Flowing Water

Place Water

Place Lava

Place Empty

Lavacast

Explode Base

Entity Changes

BAD reputation changes how some entities behave.

Triggering Null (Chase) from Null (Watching) will instead trigger Null (Unbeatable Bossfight).

Null (Scare) will have a 10% chance to trigger Null (Endgame) instead.

The "Friend?" response will cause Null (Scare) instead of the normal response. It is currently the only way to self-check reputation without commands.
